 macOS 安装包 已匹配当前系统

支持 macOS 12+（Apple Silicon M1–M4 与 Intel 通用原生窗口）

  1. 1. 下载并打开 .dmg 镜像，将 OmniAgent 拖入「应用程序」或桌面；
  2. 2. 进入文件夹双击 OmniAgent.app 或 启动桌面端.command（首次自动配好环境）；
  3. 3. 在自动弹出的「设置 → 模型密钥」中填入你的 DeepSeek / OpenAI / Qwen Key 即可使用。

⊞ Windows 安装包 已匹配当前系统

支持 Windows 10 / Windows 11（64位，内置离线中文 OCR 与独立桌面窗口）

  1. 1. 下载 .zip 后右键选择「全部解压缩」到桌面或任意文件夹；
  2. 2. 双击 启动桌面端.bat 或 启动桌面端(无黑框).vbs（若未装 Python 会自动静默安装）；
  3. 3. 在自动弹出的「设置 → 模型密钥」中填入你的 DeepSeek / OpenAI / Qwen Key 即可使用。
