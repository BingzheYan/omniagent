OmniAgent 快速上手指南

支持 Windows 10/11 与 macOS 12+ 开箱即用：自动完成 Python 虚拟环境隔离配置，保护你的 API 密钥安全。

1. Windows 电脑安装与启动

  1. 从官网下载 OmniAgent-v0.2.0-Windows-x64.zip；
  2. 右键点击压缩包，选择「全部解压缩」到桌面或任意目录（请先解压到文件夹后再运行，勿直接在压缩包预览窗口内双击）；
  3. 打开解压后的 OmniAgent 文件夹，直接双击 启动桌面端.bat：
    • 若电脑尚未安装 Python 3.10+，脚本会自动下载并静默安装官方 Python 3.12（用户级安装，无需管理员权限）；
    • 自动创建独立的 .venv 虚拟环境并从国内高速镜像安装全部依赖（首次约 1–2 分钟）；
    • 后续每次日常使用可双击 启动桌面端(无黑框).vbs，无黑色命令行窗口直接打开深色桌面工作台；也可运行 环境安装与自检.bat 在桌面生成快捷方式。

2. macOS 电脑安装与启动

  1. 下载 OmniAgent-v0.2.0-macOS-Universal.dmg 并双击打开；
  2. 将 OmniAgent 拖入 Applications（应用程序） 或桌面；
  3. 进入 OmniAgent 文件夹，双击 启动桌面端.command 或 OmniAgent.app（首次若提示“无法验证开发者”，右键点击 启动桌面端.command 选择「打开」即可自动解除隔离并配好环境）。

3. 配置模型 API Key

首次启动进入工作台时，系统会自动弹出「设置 → 模型密钥」面板。你的 API Key 采用本机对称密钥加密存储，仅保存在你自己的电脑上。
  • 图形界面配置（推荐）：点击左下角头像 →「偏好与模型密钥」→「模型密钥」，在 deepseek（或 openai / qwen / kimi / glm / claude）右侧点击「设置」，填入你的 sk-... 保存即可立即对话。
  • 配置文件方式：也可编辑文件夹根目录下的 .env 文件（例如写入 DEEPSEEK_API_KEY=sk-xxx）。

4. 三种客户端形态

  • 桌面端（Desktop）：Windows 双击 启动桌面端.bat / macOS 双击 OmniAgent.app，自动分配本地端口并免密登录独立窗口。
  • Web 工作台（Workbench）：Windows 双击 启动Web工作台.bat / macOS 双击 启动Web工作台.command，支持多用户账号、分享链接与管理后台。
  • 命令行终端（CLI）：双击 启动命令行CLI，或在虚拟环境中执行：
omni                                  # 交互式智能体终端
omni --agent coder run "修复测试报错"   # 指定工程师智能体自动执行任务
omni agents                           # 查看全部智能体与子智能体
omni skills                           # 查看内置专业技能包

5. 内置 7 大专业智能体

  • general（全能主控）：任务拆解、并行委派多个子智能体与整体交付核验；
  • coder（软件工程师）：复现 → 根因定位 → 最小改动 → 回归测试；
  • researcher（调研专家）：高速只读检索代码库、文档与网页资料；
  • analyst（数据与计量分析师）：持久化 Python 内核、面板固定效应 PanelOLS/DID 与出版级图表；
  • writer（论文与公文主笔）：《财政研究》等期刊论文、GB/T 9704 党政机关公文排版；
  • connector（外部连接专家）：REST/GraphQL、SQLite、邮件日历、MCP 与业务网页提取；
  • reviewer（质量审查员）：独立单测、check_document 规范打分与 view_image 图表视觉自检。

6. 外部业务系统与安全机制

当智能体通过 web_automation 操作需要登录的报销、OA、ERP、招聘等网页系统时，遇到登录页会在对话中弹出「需要你登录」安全卡片并置前浏览器窗口，由你本人完成账号/扫码/验证码登录（绝不代填密码或绕过验证）；任何最终提交、外发邮件等不可逆操作均需你确认后才会执行。
